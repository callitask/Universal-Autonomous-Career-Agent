# default_user: Master Candidate Blueprint

This directory is the **universal starter blueprint** for onboarding candidates onto the **Universal Autonomous Career Agent**.

---

## Contents

- **`candidate_config.json`**: Complete, fully annotated configuration template with bracketed placeholders (`[PLACEHOLDER]`) covering personal details, target roles, campus/internship settings, ATS screening answers, and profile synchronization fields.
- **`resume.md`**: Clean, professional Markdown resume template with sections for summary, core competencies, experience, internships/projects, education, and certifications.
- **`output/`**: Placeholder directories (`applications/`, `logs/`, `resumes/`) demonstrating the structure auto-generated by the agent at runtime.

---

## How to Use This Template

1. **Do not run the agent directly on `default_user`.** The core engine explicitly skips this folder during candidate auto-discovery.
2. **Copy this folder** to create a new candidate sandbox:
   ```powershell
   Copy-Item -Recurse profiles/default_user profiles/<candidate_firstname_lastname>
   ```
3. **Open the copied folder and edit the two prerequisite files**:
   - `candidate_config.json`
   - `resume.md`
4. **Launch the agent** with your new profile:
   ```powershell
   python core/04_job_discovery.py --profile profiles/<candidate_firstname_lastname>
   ```
